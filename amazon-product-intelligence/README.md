## Project Overview
This project analyzes a curated dataset of Amazon India products (pricing, discounts, ratings, reviews) to answer business questions and build a product segmentation that supports market and merchandising decisions.

Deliverables include:
- Cleaned datasets and engineered features
- Product Score Index (PSI) ranking
- KMeans segmentation with model artifact
- Sentiment analysis on review text
- A standalone offline dashboard (single HTML file)
- A written business report with quantitative answers and recommendations

## Business Questions
The analysis answers 20 business questions across:
- Data quality and coverage
- Pricing and discount dynamics
- Ratings and engagement patterns
- PSI rankings and category leaders
- KMeans-based product segments and opportunity sizing
- Review sentiment vs. numeric ratings

The full Q&A is available in: `reports/business_questions_report.md`.

## How to Run
1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Put the dataset at:
   - `data/raw/dados_amazon.csv`
4. Run notebooks in order (from `notebooks/clean/`):
   - `01_eda_e_qualidade.ipynb` → `07_storytelling_executivo.ipynb`
5. Open the dashboard (offline):
   - `dashboard/index.html`

## Key Findings
- PSI surfaces products that combine strong ratings, meaningful discount, and high review volume (not just rating alone).
- Discounts above 50% tend to cluster into distinct price bands; pairing discount with engagement avoids “too-good-to-be-true” traps.
- A small subset of products concentrates a large share of total reviews, revealing clear category leaders.
- Clustering separates premium/highly-rated products from budget/high-discount segments, enabling different merchandising strategies.
- Text sentiment can diverge from numeric rating, highlighting categories where review text provides extra signal.
